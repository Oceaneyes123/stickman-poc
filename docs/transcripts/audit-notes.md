# Audit notes

All manual anchors and all table excerpts were checked as exact substrings against the transcript bodies. Word counts and positions were computed from the same body text. Sentence splitting was checked to preserve every whitespace token. Beat anchors were checked in ascending source order. Phrase counts are case-insensitive literal-substring counts, and direct-address counts use the separate whole-token rule stated above.

Skipped: raw audio/video review, outside sources, financial verification, measured runtimes, and performance analysis. Main risk: recognition errors and small per-channel samples limit sentence, phrase, and formula conclusions.
