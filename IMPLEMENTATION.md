# Money Trap POC

The executable project is `money-trap/`, scaffolded with the official blank Remotion 4.0.541 template. Existing reference documents remain intact. No other video project is modified.

## Architecture and execution plan

1. Foundation: strict TypeScript, pinned Remotion packages, local fonts, Studio, two registered compositions.
2. Characters: one articulated SVG rig, fixed segment lengths, two-bone IK, planted feet, pose blends, identity wrappers, expression and gesture gallery.
3. Finance: one hypothetical dataset, pure arithmetic and tests, eight reusable graphical components.
4. Scenes: story, comparison and diagram templates; frame-driven reveal, camera and transition primitives.
5. Timeline: narration text, editable phrase cues, cue-relative storyboard; validation and deterministic compiler; one global WAV track when supplied.
6. Film: seven lifestyle-creep beats, 78-second silent timing demo while WAV is absent; actual WAV metadata determines duration once aligned.
7. QA: strict lint/typecheck, focused tests, gallery/stills, 1080p H.264 render, ffprobe, full decode and contact sheets from encoded output.

## Production gates

Technical execution is authorized by the brief, including local rendering. Character quality and listening approval remain human review gates; never label those as passed by an automated test. No audio exists at initial inspection; phrase timestamps are estimates and synchronization remains unverified.
